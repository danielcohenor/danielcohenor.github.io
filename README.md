# Daniel Cohen-Or website

A dependency-free static website. No Jekyll or build step is required.

## Local preview

Open `index.html` directly in a browser. No local server or build process is required.

## Updating publications

Edit `data/publications-data.js`. Only records with `"type": "paper"` are displayed. Images are optional; records without one use the shared fallback thumbnail.

## Deployment

The entire directory can be published directly with GitHub Pages. No compilation is required.
